# CREO | Website estático

Web estática de una sola página preparada para publicar en GitHub Pages.

## Archivos

- `index.html`: página principal completa con HTML y CSS integrados.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo: `creo-website`.
2. Sube el archivo `index.html` a la raíz del repositorio.
3. En GitHub entra en **Settings**.
4. Ve a **Pages**.
5. En **Build and deployment**, selecciona:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/root**
6. Guarda los cambios.
7. GitHub generará una URL similar a:
   `https://tuusuario.github.io/creo-website/`

## Personalizar

- Cambia el correo `contacto@creo.org` por tu correo real.
- Sustituye la imagen principal por una foto propia o una imagen libre de derechos.
- Puedes cambiar los colores editando las variables CSS dentro de `:root`.
